CertiChain evidence 03

MetaMask integration

The frontend implements the standard EIP-1193 MetaMask connection flow through Ethers.js and creates a signer-backed contract instance for transactions.

Integration implemented
Providerwindow.ethereum
LibraryEthers.js 6
Connection requestethereum.request({ method: "eth_requestAccounts" })
Signer-backed contractnew ethers.Contract(config.address, config.abi, signer)
provider = new ethers.BrowserProvider(window.ethereum)
signer = await provider.getSigner()
contract = new ethers.Contract(config.address, config.abi, signer)

A live connected-wallet screenshot requires the MetaMask browser extension, which was not installed in the available Chrome profile.
